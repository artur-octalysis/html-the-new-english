# A small first contribution

This is a facilitator example, not a team submission.

- Audience: a fictional new community member.
- Desired behavior: offer one idea that another person can build on.
- Motivation hypothesis: a small, acknowledged contribution may make starting feel achievable (Development & Accomplishment).
- Run: open index.html in a browser or present it in the gallery.
- Check: choose a topic, submit an empty idea, submit a short idea, and reset.
- Limitations: no persistence, backend, or actual community response. This is an unvalidated design hypothesis.
- Next step: adapt the flow for someone who wants to observe before contributing.
