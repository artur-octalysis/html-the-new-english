WHAT CHANGED?


“It works locally. Why is the live site different?”
  • Different revision: check the deployed commit and the target branch.
  • Different environment: localhost URLs and local environment variables do not configure production.
  • Failed build: read the deployment logs before assuming the change is live.
  • Old browser copy: check cache and asset versions after confirming deployment succeeded.

07 / ARCHITECTURE · 4 MIN
What happens
behind the screen?
A working interface is only one part of a working product.
request ↓ ↑ response
authorized read / write ↓ ↑ result


The decisions your AI needs from you
  • Identity and access: who can read or change which records? Signing in proves identity; authorization grants access.
  • Secrets: private API keys belong on the server. Anything sent to the browser can be inspected.
  • Data rules: define fields, valid values, ownership, duplicate handling, and relationships.
  • Failure behavior: show saving, success, and failure. Retrying must not accidentally award the same activity twice.
  • Environments: test with sample data and separate credentials before changing production. A database schema change needs a migration, not just new HTML.
In this workshop: Pages serves the website. A Vercel API handles presenter sign-in and GitHub writes. The fitness activities are still a browser-only demo.

A CONNECTED PRODUCT
An authenticated API checks the user and values, saves the activity, then returns the saved record. Reopening the app fetches it again.
What a real activity table needs
id · user_id · activity_type · minutes · created_at
  • A unique ID distinguishes one activity from another.
  • User ownership and enforced access rules keep each person’s records separate.
  • Validation rejects invalid minutes and unsupported activity types.
  • A stable request ID or unique constraint prevents duplicate submissions.
  • Only confirm “saved” after the service acknowledges the write.
A new activity changes data, so it does not require a deployment. Changing how the app displays or processes that activity changes code, so it does.
