## Interface
The cover hides the right panel. Later chapters show a wider, shorter folder with actual published pair files and an inspect/download dialog. The HTML/CSS/JS chapters switch to a sandboxed live preview. Arrow left/right navigates outside editing controls. Mobile puts the repo beside its current content and uses a compact floating live preview.

The strategy dashboard schematic has been removed. Briefs carry fictional business metrics, audience, challenge and acceptance checks. Context stays readable in Markdown. Repository files come from a build-generated manifest; browser edits never pretend to write to GitHub.
